具体要求：

1. 请求校验
- 定义 createUserRequestSchema
- Schema 统一包含 body、params、query
- 使用 validateRequest 中间件校验
- 校验结果保存到 res.locals.validated
- Controller 不再直接信任 req.body

2. DTO 和 Entity
- CreateUserRequest：完整校验结果类型
- CreateUserDto：CreateUserRequest['body']
- User：内部实体，createdAt 为 Date
- UserOutput：接口输出，createdAt 为 string

3. Repository
- 定义 UserRepository interface
- findByEmail(email): Promise<User | null>
- create(input): Promise<User>
- 实现 MysqlUserRepository
- 数据库邮箱字段必须有唯一约束
- 将数据库唯一键冲突转换成 DuplicateUserEmailError

4. Mapper
- UserRow 表示数据库原始行
- toUser(row) 将 id 和 created_at 转换为内部 User
- toUserOutput(user) 将 Date 转成 ISO 字符串
- 校验 JavaScript 安全整数和有效时间

5. Service
- 使用展开式构造函数，不要参数属性简写
- 先 findByEmail
- 邮箱存在时抛 AppError 409
- 调用 repository.create
- 捕获 DuplicateUserEmailError 并转换为相同的 AppError
- 其他错误原样抛出
- 返回 UserOutput

6. Controller
- 使用 createUserController(service) 工厂函数
- 从 res.locals.validated 读取 CreateUserRequest
- 调用 service.create(body)
- 使用 sendSuccess 返回 201

7. 错误中间件
- 四参数签名
- 处理 res.headersSent
- AppError 按 statusCode 返回
- 未知错误记录日志并返回 500
- 不向前端泄漏 stack

8. 依赖组装
必须在 user.module.ts 或 composition-root.ts 中明确写出：
- new MysqlUserRepository(...)
- new UserService(repository)
- createUserController(service)
