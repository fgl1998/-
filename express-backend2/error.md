| HTTP | 含义               | 常见场景                 |
| ---- | ---------------- | -------------------- |
| 400  | 请求有问题            | 参数格式错误               |
| 401  | 没登录/认证失败         | token 不存在或无效         |
| 403  | 已识别身份但没权限        | 普通用户访问管理员接口          |
| 404  | 资源不存在            | 用户、订单不存在             |
| 409  | 当前状态冲突           | 邮箱重复、订单已经支付          |
| 422  | 参数格式可能合法，但业务无法处理 | 某些业务校验失败             |
| 500  | 服务端未知异常          | SQL bug、数据库挂了、程序 bug |
