# App.vue 的作用

## 1. 应用生命周期入口

`App.vue` 是 uni-app 中唯一能监听**应用级生命周期**的地方：

| 生命周期 | 触发时机 |
|---------|---------|
| `onLaunch` | 小程序初始化完成时（全局只触发一次） |
| `onShow` | 小程序启动或从后台进入前台时 |
| `onHide` | 小程序从前台进入后台时 |

## 2. 全局样式定义

`App.vue` 中 `<style>` 内的样式是全局公共样式，会作用于所有页面。

## 3. 应用根实例的构建入口

在 `main.js` 中，`App.vue` 的导出对象被展开到 `new Vue()` 中，成为整个小程序的根 Vue 实例。
